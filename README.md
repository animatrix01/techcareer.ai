# TechCareer.AI

An AI-powered career platform that helps job seekers build ATS-optimized resumes, analyze their job readiness, and create personalized career roadmaps. Built with Next.js 15, TypeScript, and modern AI technology.

## What It Does

TechCareer.AI is an all-in-one career development platform featuring three core tools. The Resume Builder offers 20+ professionally designed, ATS-optimized templates with AI-powered content suggestions that help users create compelling resumes. The Resume Analyzer provides instant feedback on ATS compatibility, keyword optimization, and content quality with actionable insights. The Career Roadmap Builder generates personalized learning paths based on career goals, identifies skill gaps, and tracks progress over time.

## Technology

Built with Next.js 15 and TypeScript for a fast, type-safe experience. Uses Tailwind CSS 4 and Framer Motion for a modern, animated interface. Authentication powered by Clerk, with data stored in Neon PostgreSQL using Drizzle ORM. Features custom AI integration for intelligent content generation and career guidance.

## Features

Create professional resumes with drag-and-drop editing, real-time preview, and one-click PDF export. Upload existing resumes for smart parsing and editing. Get detailed ATS scoring with specific improvement recommendations. Generate AI-powered career roadmaps with personalized learning resources and milestone tracking. All tools work together seamlessly in a responsive, mobile-friendly interface.
